# Piloto RD Vendas

Cópia do protótipo navegável (wave 3) — criação de links de pagamento no RD Station CRM, com checkout TOTVS Pay.

## Demo

https://luiza-jung-rd.github.io/piloto-rd-vendas/

## Rodar localmente

```bash
npm install
npm run dev
```

O app abre na negociação **Projeto MRV - Mário e Tarsila**. O fluxo está no bloco **Pagamentos**.

Design system: Tangram (`docs/DESIGN.md`).
